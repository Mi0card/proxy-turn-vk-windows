Правила маршрутизации
Справка по правилам (формат и политики)

Формат: geosite-category-ru, geoip-private, а также встроенные правила domain:example.com (точно), domain-suffix:example.com (домен + поддомены), keyword:text, regex:\.example\.com$, cidr:10.0.0.0/8, ip:1.2.3.4 — они работают без скачивания правил. Правила применяются сверху вниз — первое совпадение выигрывает. Политики: block (заблокировать), direct (напрямую, в обход туннеля), proxy (через туннель).
Трафик, к которому не подошло ни одно правило, направляется по выбору «Трафик по умолчанию» (вверху): proxy / direct / block.
Подсказки: начните вводить, чтобы увидеть доступные правила.
